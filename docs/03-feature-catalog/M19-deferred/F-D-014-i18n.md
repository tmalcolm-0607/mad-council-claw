# F-D-014 — Internationalization (i18n) (DEFERRED)

## Status

**Deferred to v1.5+ per `rules/no-silent-deferrals.md`.**

## Summary

End-to-end internationalization: extract every user-visible string into a localizable resource, support runtime locale switch, render error messages + briefing templates + documentation in the active locale, enable non-English search in M18 marketplace, support locale-aware date / number / currency formatting. v1 is en-US + UTC only; this item makes every surface localizable.

## Re-open trigger

Re-open this item when ANY of the following user-acknowledged conditions are met:

1. A non-English-speaking user asks to use the engine in their language.
2. A regulated environment (Microsoft-internal regional compliance, customer territory rules) requires localized UI.
3. A v1.5+ launch targets a non-en-US market explicitly.
4. The user explicitly requests "I want this to support [language X]."

Until then, this ledger remains `status: deferred` and SHOULD NOT be transitioned to RED.
