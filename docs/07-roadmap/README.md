# 07 — Roadmap

Milestone timeline, per-feature status history, and decision log.

## Contents (populated wave-by-wave)

- `milestones-timeline.md` — M0..M19 with dependencies and estimated wall-clock per milestone
- `current-wave.md` — which wave is running NOW (this file is also referenced from `docs/11-loop-state/current-wave.md` — see that for the multi-instance pickup protocol)
- `status-history.md` — per-feature RED → GREEN → LOCKED transitions, append-only
- `decision-log.md` — D-1..D-N decisions with date, rationale, commit SHA reference

## Per Goal G9 (Message 6)

The full feature catalog with milestones is the contract; nothing implements without a milestone home. The roadmap is what makes the catalog navigable.

## Per Goal G20 (Message 25)

Self-improving from day 1: the roadmap auto-updates on merge, and the metric pack is generated weekly from the status history.
